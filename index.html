Pengaturan TMDB API Key

Dimana Memasukkan API Key?

Masukkan kode TMDB API Key Anda pada kolom di bawah ini lalu klik tombol "Simpan API Key". Sistem akan menyimpannya secara otomatis.

Cara Mendapatkan TMDB API Key Gratis:

  1. Buka website resmi TheMovieDB.org dan buat akun gratis.
  2. Masuk ke profil Anda -> Pilih Account Settings -> Menu API.
  3. Klik Create / Request API Key (Developer).
  4. Salin kode API Key (v3 auth) (berisi 32 karakter huruf & angka) dan tempel di bawah.
